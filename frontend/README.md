# Frontend — SkinCorpus

Interface web moderna, responsiva e de alta performance desenvolvida com **React 19**, **TypeScript** e **Vite**.

## Tecnologias Utilizadas

- **React 19**: Biblioteca para construção de interfaces reativas e componentizadas.
- **TypeScript**: Tipagem estática para maior segurança e manutenibilidade do código.
- **Vite**: Ferramenta de build rápida com suporte a Hot Module Replacement (HMR).
- **React Router v7**: Roteamento SPA no cliente sem recarregamento de página.
- **CSS Vanilla (CSS Modules + Tokens)**: Estilização modular com design system baseado na paleta oficial da clínica (Creme e Dourado).
